About Me

I'm Yarima, a full stack developer based in Ghana. I build software that actually works in the real world, not just in a demo.

I write front end with React and Tailwind, and back end with Python. I also work with SQL and data engineering, something I picked up through the data engineering course I'm completing right now at ALX. So I'm not boxed into one layer of the stack — I go wherever the problem needs me to.

My current projects include a smart GPS tracker for livestock at Umar's livestock farm. I'm building the tracker from the ground up, hardware and software, for small farms in Ghana that don't have access to expensive tracking systems. It tracks an animal's location, flags when it crosses a boundary, and sends alerts. Still a work in progress, but it runs.

Before this, I worked as a data specialist at AYA Data, and moved into a front end developer role with them on contract. I'm currently freelance.

I'd rather ship something real and keep improving it than wait until it's perfect. That's how most of my work gets built.

from fastapi import FastAPI
import joblib
import numpy as np

app = FastAPI()

model = joblib.load("model.joblib")
scaler = joblib.load("scaler.joblib")

@app.post("/predict")
def predict(features: list[float]):
    X = np.array(features).reshape(1, -1)
    X_scaled = scaler.transform(X)
    prediction = model.predict(X_scaled)[0]
    result = "malignant" if prediction == 0 else "benign"
    return {"prediction": result}
